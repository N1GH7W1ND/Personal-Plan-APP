# 页面结构与交互设计

> 这份文档描述的是**当前实现**的界面结构与交互，与代码保持一致。
>
> 早期有一版 v1 设计稿（当时还规划了自媒体、咨询工作、游戏娱乐、健身计划四个模块），
> 那四个模块后来按需求变更移除了，本文件已按现状重写。
> 完整的范围变更记录见 `PRD.md` 的「范围变更记录」。

---

## 0. 设计原则

1. **一屏之内能干活**：任何页面打开后，最常用的动作（加一条、勾一下）不用翻页、不用点开弹窗才能做。
2. **任务只有一份**：任务归属某个板块、带一个日期。板块页和首页看的是同一份，绝不复制。
3. **不替你做决定**：系统只提醒，是否挪动、是否采纳由你点。首页不生成任何任务。
4. **空状态也要有用**：新的一天/新板块打开时显示「可以做什么」，而不是一片空白。
5. **数据看得见摸得着**：随时知道数据存在哪个文件、上次保存是什么时候。

## 1. 全局骨架

### 1.1 布局：左侧固定导航 + 右侧内容区

```
┌──────────────┬─────────────────────────────────────────────┐
│  ☰ 我的工作台 │  页面标题        [日期]      [快速添加] ●已保存│  ← 顶栏
│              ├─────────────────────────────────────────────┤
│  ● 首页总览   │                                             │
│  ○ 今日计划 ③ │                                             │
│  ○ 开发     ② │            内容区（整页滚动）                 │
│  ○ 学习       │                                             │
│  ○ 阅读       │                                             │
│  ○ 饮食       │                                             │
│  ○ 健身       │                                             │
│  ○ 数据与设置 │                                             │
│              │                                             │
│  ─────────── │                                             │
│  今天 3/7 完成 │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

**左侧栏分三段**：

| 段 | 内容 | 能否改 |
|---|---|---|
| 骨架 | 首页总览、今日计划 | 固定 |
| 业务板块 | 开发 / 学习 / 阅读 / 饮食 / 健身 | **可勾选、可排序**（见 3.8） |
| 骨架 | 数据与设置 | 固定 |

**导航项上的数字**是「今天还没做完的任务数」，一眼看出哪个板块欠账。

**为什么用左侧导航**：板块放顶部标签会挤；左侧常驻才能显示计数徽标，且以后增减板块不用改布局。

### 1.2 顶栏做两件事

| 元素 | 作用 |
|---|---|
| 页面标题 | 当前在哪 |
| 快速添加（`+` / 快捷键 `A`） | 不离开当前页就能新增任务；弹窗里可选"加到哪个板块 + 哪天 + 哪个优先级" |
| 保存状态点 | 灰点=已保存、黄点=保存中、红点=保存失败（可点开看原因） |

### 1.3 全局快捷键

| 键 | 动作 | 备注 |
|---|---|---|
| `1`–`8` | 按左侧顺序切到对应页面 | 正在输入框里打字时，数字键属于输入内容 |
| `A` | 打开「快速添加」 | 同上，输入时不触发 |
| `Esc` | 关闭弹窗 | |
| `Enter` | 在快速添加 / 快速备忘的输入框里回车即提交 | |

> 早期设计稿里写过 `/` 聚焦搜索，**这个功能没有实现**，已从文档中去掉。

## 2. 首页总览

首页是「今天开工第一眼」，左右两列**等宽**：

```
┌───────────────────────────────┬──────────────────────┐
│ ① 今日计划                     │ ③ 快速备忘            │
│   4/9 已完成 ▓▓▓▓░░░░          │  ┌────────────────┐  │
│   ☑ 改登录接口 bug     开发    │  │ 买点水果        │  │
│   ☐ 写周报             通用    │  │ 交话费          │  │
│   ☐ 胸+三头 训练       健身    │  │ + 记一笔…        │  │
│   ─────────────────────      │  └────────────────┘  │
│   ⚠ 逾期 2 条 >               │                      │
│   [查看全部 →]                │  （这一列整列都是备忘） │
│                              │                      │
│ ② 快速补一条（下拉选板块）     │                      │
│   板块▾ [ 内容… ] [回车添加]  │                      │
└───────────────────────────────┴──────────────────────┘
                          ④ 各模块汇总（柱形图 + 扇形图）
```

**右列的高度随备忘条数增长**，超过上限就在卡片内纵向滚动，不会把左列拉长。

> 早期设计稿里这里还有一块「④ 待你处理（摘要区）」，**已按需求删除**，
> 腾出的位置并给了快速备忘。

### 2.1 今日计划卡（主角，占最大面积）

- 只显示"日期 = 今天"的任务，来源板块以彩色小标签标出。
- **直接勾选**完成，无需跳转；勾完进度条即时更新。
- 逾期任务折叠在下方一行（`⚠ 逾期 2 条`），点开可挪到今天 / 改到别的日期 / 完成。
- 空状态：`今天还没有安排`，并提示从哪儿加。

### 2.2 快速补一条

**不做智能建议**：首页不会出现 `+ 安排健身` 这类系统生成的入口，也不自动创建任何任务。

补任务只有两个入口：

1. **顶栏「快速添加」**：弹窗里选板块 + 日期（默认今天）+ 优先级（默认「重要且紧急」）。
2. **首页「快速补一条」**：一行输入，左边下拉选板块，回车即加。下拉里的板块与顺序**跟随左侧栏的勾选设置**（见 3.8）。

> 设计取舍：首页保持"只显示你亲手排的事"，一眼看过去全是自己的决定，没有系统替你操心。

### 2.3 快速备忘

- 纯便签：输入框回车即存，点文字编辑，划掉=完成。
- **不归属任何板块**：数据里没有 module 字段，不参与完成率、不进逾期、不算进任何板块欠账。
- 可以"升级"：点便签上的 `→ 变任务`，转成正式任务并选择板块和日期（默认今天）。

### 2.4 各模块汇总图表

- 切时间范围 `本周 / 本月 / 今年 / 全部`。
- 柱形图看每天（或每月）的任务量与完成量；扇形图看**各板块的任务分布**。
- 点柱子或扇区 → 下方明细只显示那一段；点 `看全部` 取消。
- 点扇形图例里的**板块名**可跳到该板块。

## 3. 页面清单与逐个板块结构

统一规律：**顶部一行概况（数字/进度）→ 中间核心工作区 → 底部该板块专属区**。

每个板块页最终都收敛成三样东西：**自己的清单 → 自己的月历 → 自己的统计图表**。

### 3.1 今日计划

```
[ ◀ 10月8日 周三 ▶ ]  [今天]     今日 4/9 · 逾期 2
─────────────────────────────────────────────
☑ 改登录接口 bug          开发     [···]
☐ 写周报                  通用     [···]
─────────────────────────────────────────────
⚠ 逾期（10月6日）
☐ 整理会议纪要  开发  [挪到今天][改期][完成]
─────────────────────────────────────────────
这一天的小结 / 任务日历
```

- 日期可前后翻，能看过去/未来哪天排了什么。
- 每条右侧 `[···]`：改日期、改优先级、删除。
- 逾期区提供"全部挪到今天"。

### 3.2 开发

**结构：待办清单 + 灵感收集箱**

```
[+ 加待办]
☐ 改登录接口 bug   [开发中]  ⚑   [推送到今日]
☐ 重构订单模块     [未开始]
☑ 部署测试环境     [已上线]
状态四档：未开始 / 开发中 / 联调测试 / 已上线（点标签直接切）

💡 灵感收集箱（随手记，不用选择分类）
· 用缓存把首页数据加速        [变成待办] [删除]
```

- **灵感箱**的价值：看到什么随手丢进来，之后一键"变成待办"，避免打断当前工作。
- 顶部概况：`进行中 2 · 今日完成 1`。

### 3.3 学习

**结构：学习清单（类型 + 进度 + 已学时长）**

```
[+ 加内容]
☐ 《深入理解计算机系统》第 3 章   [课程] [学习中] 45 分钟  [推送到今日]
☐ 刷两道动态规划                 [练习] [未开始]
☑ 看完那集公开课                 [视频] [已学完]
类型五档：阅读 / 课程 / 练习 / 视频 / 其他
进度三档：未开始 / 学习中 / 已学完（点标签直接切）
```

- 顶部概况：`学习中 1 · 今日完成 0`。
- 统计里会累加"已学时长"。

### 3.4 阅读

**结构：我的书（书架 + 进度）+ 读书笔记**

```
[+ 加一本书]
《Educated》  ★★★★★  [在读]  ▓▓▓▓░░░░ 60/200 页  [记阅读] [记笔记] [推送到今日]
《人类简史》  　      [想读]
书架四态：想读 / 在读 / 已读完 / 搁置

今日目标 30 分钟 · 本周 ▓▓▓▓░░░

读书笔记（就在本页）
[搜索框]  [按书筛选▾] [按类型筛选▾] [只看收藏]
· 摘抄 · 《Educated》 第 3 章 · 第 42–45 页 · 第 3–8 行
  「你当像鸟飞往你的山」                      [收藏] [编辑] [删除]
笔记四类：摘抄 / 想法 / 疑问 / 待办
```

- **加书**填书名即可；填了总页数才有进度条。新建时若已填"读到第几页"，状态自动变「在读」。
- **推进进度**：编辑书时直接填"已读到第几页"，或记阅读时顺便填。读到最后一页 → **自动「已读完」**并记完成日期。
- **笔记位置**：章节 + 页码区间 + 行号区间，可以只填一半（只填"到第几页"会自动把起始页补成同一个）。
- **删书会连带删掉它的笔记**（笔记挂在书上），5 秒内可撤销。

### 3.5 饮食

**结构：今日三餐 + 常吃菜谱 + 采买清单**

```
今日三餐
早餐 [ 燕麦鸡蛋        ▾ 从菜谱选 ]
午餐 [ 鸡胸西兰花      ▾ ]
晚餐 [ 番茄牛腩        ▾ ]
────────────────────────────────────────
⭐ 常吃菜谱                      🛒 采买清单
· 番茄牛腩  [→ 安排到今天]        ☐ 牛腩
· 鸡胸西兰花 [→ 安排到今天]       ☑ 西兰花
[+ 存一道菜]                     [+ 加一项]  [清空已买]
```

- **菜谱**是"决定今天吃什么"的加速器：收藏常做的，一键排到某天。
- **采买清单**独立勾选，买菜时用；勾完可一键清空已买项。
- 顶部概况：`三餐已定 2/3`。

### 3.6 健身

**结构：今天 + 训练目标 + 训练日志 + 训练记录**

```
[记一次训练]
今天：胸 + 三头 · 45 分钟 · 吃力
  卧推 4×12 · 上斜哑铃卧推 3×10 · 绳索下压 3×15
本周练了 2/3 次 · 连续 4 天

训练目标
· 胸 + 三头  每周 2 次   1/2   [记一次] [编辑]
· 有氧       每周 1 次   1/1   已达标

训练日志
· 10月8日 · 胸 + 三头 · 45 分钟 · 吃力   [编辑] [删除]

训练记录（文字）
· 今天状态不错，卧推最后一组有点吃力
```

- **只填时长、或只填动作**都算一次训练；两样都没有才不记录。
- **动作写法**：`卧推 4x12`、`卧推 4 x 12`、`卧推 4 12` 都认。
- **同一天记两次会合并**：时长累加，同名动作合并（组数累加、次数取更好的）。
- **连续天数**：今天还没练不算断（从昨天往前数）。
- 强度三档：轻松 / 正常 / 吃力。类型：胸 + 三头 / 背 + 二头 / 腿 + 肩 / 有氧 / 核心 / 拉伸 / 其他。

### 3.7 统计与日历（每个板块都有）

- **月历**：周一开头，今天那格有边框；有内容的日子显示圆点，**完成的点是绿色**；点某天展开那天的内容，再点收起。
- `◀` `▶` 翻月，`回到本月` 一键跳回。**每个页面的月份各自独立**——在开发页翻到下个月，学习页仍是本月。
- **图表**：柱形图 + 扇形图，可切时间范围，可点选筛选明细（同 2.4）。
- **日历和图表只看不改**：翻月、切范围、点柱子都不会改动数据。

### 3.8 数据与设置

```
数据状态
· 数据文件：<文件夹>/data/data.json      [打开文件夹]
· 上次保存：今天 14:32（已保存 ●）
· 数据量：任务 128 · 备忘 12 · 健身记录 20 · …
· 每天首次写入前自动留一份备份，最多保留 20 份
· 「新的一天」以本机时间 0 点为界，固定不可改
────────────────────────────────
左侧板块选择
☑ 开发    第 1 位  [↑][↓]
☑ 学习    第 2 位  [↑][↓]
☑ 阅读    第 3 位  [↑][↓]
☑ 饮食    第 4 位  [↑][↓]
☑ 健身    第 5 位  [↑][↓]
   至少要保留一个板块。一个都不勾会自动回到只显示「学习」。
   勾了两个及以上时，「学习」也可以取消。
   首页总览、今日计划、数据与设置是骨架，固定显示，不在这里勾选。
────────────────────────────────
备份与恢复
[ ⬇ 导出备份 ]   [ ⬆ 从备份恢复 ]
────────────────────────────────
⚠ 危险操作
[ 清空所有数据 ]（需输入确认文字二次确认）
```

- 导出 = 下载一个备份文件；恢复 = 选一个备份文件覆盖（覆盖前会自动再存一份当前数据）。
- **左侧板块选择**的顺序会同步影响：左侧栏、以及所有「快速添加」里的板块下拉顺序。
- 被取消勾选的板块只是**不显示**，板块本身和路由都还在——任务上的板块标签、旧书签仍能进去。

> 早期设计稿里的「偏好设置」整块（新的一天时间、逾期首页提醒、健身目标天数、界面密度）
> **已按需求删除**。阅读每日目标固定 30 分钟、每周健身目标固定 3 次，不再提供修改入口。

## 4. 跨板块流转规则（最容易出错的部分）

### 4.1 任务只有一个归属，多个视图

```
任务 { 内容, 归属板块, 日期, 状态, 优先级 }
   ├─ 出现在「归属板块」的清单里（永久）
   └─ 当日期 = 今天 → 出现在首页 & 今日计划
```

勾选在哪儿打，两边同时变。删掉就彻底没了。

**优先级四档**：重要且紧急 / 重要不紧急 / 不重要但紧急 / 不重要不紧急。
所有板块统一，列表按这个顺序排。**新增任务默认选中「重要且紧急」**。

### 4.2 逾期处理（不自动搬）

- 过了日期还没完成 → 标记「逾期」，**留在原日期**，首页与今日计划露出提醒。
- 提供：`挪到今天` / `改日期` / `完成`，以及一次性"全部挪到今天"。
- 为什么不一键自动顺延：自动顺延会让清单永远在滚雪球，看不住真实欠账。

### 4.3 板块 → 今日计划的两条通路

| 通路 | 场景 |
|---|---|
| 「推送到今日」按钮 | 明确知道今天要做。开发待办、学习条目、书、菜谱、训练都有这个按钮 |
| 排期（日期） | 到那天自动出现在首页与今日计划 |

（首页**不提供** `+ 安排健身` 这类建议入口。）

### 4.4 从首页跳回板块

来源标签可点，跳到该板块并高亮那条任务，避免在 8 个页面之间凭记忆找。

### 4.5 删书的连带规则

笔记挂在书上。**删书会连带删掉它的笔记**，避免留下"找不到主人"的数据。
未关联任何书的笔记**不受影响**。整个操作 5 秒内可撤销。

## 5. 反馈与状态

| 场景 | 表现 |
|---|---|
| 保存中 | 顶栏黄点「保存中…」 |
| 已保存 | 绿点「已保存 14:32」 |
| 保存失败 | 红点 + 提示「数据没写进去，点我看原因」，并保留在内存里不丢 |
| 删除 | 立即消失 + 底部「已删除 · 撤销」5 秒（备忘、书、笔记、训练、目标等都可撤销） |
| 空列表 | 显示建议动作，不是空白 |
| 操作冲突（另一个窗口改了同一份数据） | 提示"数据已被其他窗口更新，点击刷新"，不静默覆盖 |
| 数据文件损坏 | 启动时自动从最近备份恢复，并提示；坏文件改名成 `data.broken_时间.json` 留证据 |

## 6. 已确认的设计选择

| # | 选择 | 结论 |
|---|---|---|
| 1 | 导航位置 | **左侧固定栏**，显示各板块今日欠账数 |
| 2 | 首页智能建议 | **不要**。首页只显示亲手安排的任务 |
| 3 | "新的一天" | **固定 0 点**（本机时间），不提供设置项 |
| 4 | 首页「待你处理」摘要区 | **已删除**，位置并入快速备忘 |
| 5 | 设置页「偏好设置」 | **已删除**，阅读/健身目标用固定默认值 |
| 6 | 左侧板块可配置 | **可勾选 + 可排序**；至少保留一个板块 |
