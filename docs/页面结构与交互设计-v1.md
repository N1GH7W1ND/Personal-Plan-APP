# 个人工作生活 App · 页面结构与交互设计（v1）

> 状态：设计待确认 · 不涉及代码
> 已锁定前提：本地文件夹 + 启动脚本；数据以文件形式存在文件夹内；只做「计划 + 打卡」；开发/咨询/自媒体不分项目客户；任务只有一份，首页自动汇总。

---

## 0. 设计原则

1. **一屏之内能干活**：任何模块打开后，最常用的动作（加一条、勾一下）不用翻页、不用点开弹窗才能做。
2. **任务只有一份**：任务归属某个模块，靠日期进入首页，绝不复制。
3. **不替你做决定**：系统只提醒和建议，是否挪动、是否采纳由你点。
4. **空状态也要有用**：新的一天/新模块打开时显示「建议做什么」，而不是空白页。
5. **数据看得见摸得着**：随时知道数据存在哪个文件、上次保存时间。

## 1. 全局骨架

### 1.1 布局：左侧固定导航 + 右侧内容区

```
┌──────────────┬─────────────────────────────────────────────┐
│  ☰ 我的工作台 │  页面标题        [日期]      [快速添加] ●已保存│  ← 顶栏
│              ├─────────────────────────────────────────────┤
│  ● 首页总览   │                                             │
│  ○ 今日计划 ③ │                                             │
│  ○ 自媒体   ② │            内容区（整页滚动）                 │
│  ○ 开发工作   │                                             │
│  ○ 咨询工作   │                                             │
│  ○ 健身计划   │                                             │
│  ○ 饮食计划   │                                             │
│  ○ 游戏娱乐   │                                             │
│  ○ 数据与设置 │                                             │
│              │                                             │
│  ─────────── │                                             │
│  今天 3/7 完成 │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

**导航项上的数字**是「今天还没做完的任务数」，一眼看出哪个模块欠账。

**为什么用左侧导航**：9 个模块若放顶部标签会挤；左侧常驻才能显示计数徽标，且以后加模块不用改布局。

### 1.2 顶栏做三件事

| 元素 | 作用 |
|---|---|
| 页面标题 | 当前在哪 |
| 快速添加（`+` / 快捷键 `A`） | 不离开当前页就能新增本页的东西；弹窗里可切换"加到哪个模块 + 哪天" |
| 保存状态点 | 灰点=已保存、黄点=保存中、红点=保存失败（可点开看原因） |

### 1.3 全局快捷键（提效，不影响直接用）

| 键 | 动作 |
|---|---|
| `1`–`9` | 切模块 |
| `A` | 快速添加 |
| `/` | 聚焦搜索/筛选 |
| `Esc` | 关弹窗 |

## 2. 首页总览

首页是「今天开工第一眼」，按重要性从上到下：

```
┌───────────────────────────────┬──────────────────────┐
│ ① 今日计划                     │ ③ 快速备忘            │
│   4/9 已完成 ▓▓▓▓░░░░          │  ┌────────────────┐  │
│   ☑ 写公众号初稿       自媒体  │  │ 买猫粮          │  │
│   ☐ 改登录接口 bug     开发    │  │ 问物业水费      │  │
│   ☐ 15:00 客户回访     咨询    │  │ + 记一笔…        │  │
│   ☐ 胸+三头 训练打卡   健身    │  └────────────────┘  │
│   ☐ 晚饭：番茄牛腩     饮食    │                      │
│   ─────────────────────      │ ④ 待你处理            │
│   ⚠ 逾期 2 条 >               │  · 自媒体 2 篇待发布 │
│   [查看全部 →]                │  · 灵感箱 3 条未整理 │
│                              │  · 本周健身 3/5      │
│                              │                      │
│ ② 快速补一条（手动指定模块）   │                      │
│   模块▾ [ 内容… ] [加到今天]  │                      │
└───────────────────────────────┴──────────────────────┘
```

### 2.1 今日计划卡（主角，占最大面积）

- 只显示"日期 = 今天"的任务，来源模块以彩色小标签标出。
- **直接勾选**完成，无需跳转；勾完进度条即时更新。
- 逾期任务折叠在下方一行（`⚠ 逾期 2 条`），点开可**一键挪到今天 / 改到别的日期 / 直接完成 / 放弃**。
- 空状态：`今天还没有安排 → 从模块里加，或点下面的建议`。

### 2.2 快速补一条（已按决策 D8 修改）

**不做智能建议**：首页不会出现 `+ 安排健身` 这类系统生成的入口，也不自动创建任何任务。

补任务只有两个入口：

1. **顶栏「快速添加」**：弹窗里选择归属模块 + 日期（默认今天）。
2. **首页区块二的「快速补一条」**：一行输入，左边下拉选模块，回车即加。适合"就想往开发里塞一条"这种场景。

> 设计取舍：首页保持"只显示你亲手排的事"，一眼看过去全是自己的决定，没有系统替你操心。

### 2.3 快速备忘

- 纯便签：输入框回车即存，点文字编辑，划掉=完成。
- 与任务**完全隔离**，不参与完成率、不进逾期。
- 可以做"升级"手势：点一下便签上的 `→ 变任务`，转成正式任务并选择模块和日期。

### 2.4 待你处理（摘要区）

只列"需要你此刻做决定"的事，最多 5 条：待发布的稿子、灵感箱堆积、本周健身没够、游戏 "在玩" 太久没动等。每条可点进对应模块。

## 3. 页面清单与逐个模块结构

统一规律：**顶部一行概况（数字/进度）→ 中间核心工作区 → 底部或侧边该模块专属区**。

### 3.1 今日计划

```
[ ◀ 10月8日 周三 ▶ ]  [今天]     今日 4/9 · 逾期 2
─────────────────────────────────────────────
☑ 写公众号初稿            自媒体   [···]
☐ 改登录接口 bug          开发     [···]
☐ 15:00 客户回访          咨询     [···]
─────────────────────────────────────────────
⚠ 逾期（10月6日）
☐ 整理会议纪要  咨询  [挪到今天][改期][完成][放弃]
```

- 日期可前后翻，能看过去/未来哪天排了什么（变成"日程视图"）。
- 每条右侧 `[···]`：改日期、换模块、改优先级、删除。
- 批量操作条：出现"挪到今天 / 顺延一天"两个快捷按钮，处理逾期最省事。

### 3.2 自媒体

**结构：四列进度看板 + 发布排期日历**（不做数据回填）

```
[+ 新选题]  ← 输入选题后进第 1 列
┌─选题池─┬─写作中─┬─待发布─┬─已发布─┐
│ 卡片   │ 卡片   │ 卡片   │ 卡片   │
└────────┴────────┴────────┴────────┘
卡片：标题 / 平台标签 / 计划发布日期 / [→ 推送到今日]
       动一下：点左右箭头换列（也支持拖拽）

发布排期（本月）
一 二 三 四 五 六 日
      8●         ← ● = 那天有内容要发，点开看是哪篇
```

- 卡片主要动作就两个：**换列**（推进进度）和 **推送到今日**（让今天真去做它）。
- 待发布列会同步显示在首页"待你处理"里。

### 3.3 开发工作

**结构：待办清单 + 灵感/需求收集箱（上下两块）**

```
[+ 加待办]
☐ 改登录接口 bug   [开发中]  ⚑   [推送到今日]
☐ 重构订单模块     [未开始]
☑ 部署测试环境     [已上线]
状态四档：未开始 / 开发中 / 联调测试 / 已上线（点标签直接切）

💡 灵感收集箱（随手记，不用选择分类）
· 用 Redis 缓存首页数据        [变成待办] [删除]
```

- **灵感箱**的价值：看到什么随手丢进来，之后一键"变成待办"，避免打断当前工作。
- 顶部概况：`进行中 2 · 今日完成 1`。

### 3.4 咨询工作

**结构：待办 + 会议/沟通记录 + 排期**（记录是本模块的灵魂）

```
[+ 加待办]                       [+ 加会议记录]
☐ 回复王总报价单   [推送到今日]
☐ 准备周四方案会

📝 会议/沟通记录
┌──────────────────────────────────┐
│ 10月7日 · 王总 · 回访            │
│ 要点：预算压到 8 万，要分两期      │
│ 待办：出分期报价单        [提取为任务]│
│ 下次回访：10月10日        [加进计划] │
└──────────────────────────────────┘
```

- **"提取为任务"**：记录里写的待办直接变成正式任务，不用再抄一遍。
- **"加进计划"**：回访日期直接排进那天的今日计划（到那天自动出现在首页）。
- 顶部概况：`今日待办 2 · 本周会议 3`。

### 3.5 健身计划

**结构：今天该练什么（主角）+ 逐组打卡 + 本周概览**

```
今天：胸 + 三头                 本周 3/5 天 ✅
────────────────────────────────────────
卧推        12×4   ☐☐☐☐   [完成整项]
上斜哑铃    10×3   ☐☐☐
绳索下压    15×3   ☐☐☐
────────────────────────────────────────
[+ 加动作]   今日训练全部完成 → [打卡]
```

- **按部位轮换**：周安排是"推 / 拉 / 腿 / 休"循环，系统按今天该练的部位把动作列出来。
- 打卡粒度是**组**（点一个小方块亮一个），也可以直接"完成整项"。
- 本周概览用小方块显示练了几天，缺的哪天一点就补记。

### 3.6 饮食计划

**结构：今日三餐 + 常吃菜谱 + 采买清单**

```
今日三餐
早餐 [ 燕麦鸡蛋        ▾ 从菜谱选 ] ☐已吃
午餐 [ 鸡胸西兰花      ▾ ]          ☐已吃
晚餐 [ 番茄牛腩        ▾ ]          ☐已吃
────────────────────────────────────────
⭐ 常吃菜谱                      🛒 采买清单
· 番茄牛腩  [→ 安排到今天]        ☐ 牛腩
· 鸡胸西兰花 [→ 安排到今天]       ☑ 西兰花
[+ 存一道菜]                     [+ 加一项]
```

- **菜谱**是"决定今天吃什么"的加速器：收藏常做的，一键排到某天。
- **采买清单**独立勾选，买菜时用；勾完可一键清空已买项。
- 顶部概况：`三餐已定 2/3`。

### 3.7 游戏娱乐

**结构：想玩/在玩/通关 三列 + 放松时间安排**

```
[+ 加游戏]
┌─想玩─┬─在玩─┬─已通关─┐
│ 卡片 │ 卡片 │ 卡片   │
└──────┴──────┴────────┘
卡片：游戏名 / 平台 / 备注 / [开始玩] [通关]

🎮 放松时间
本周安排：三、六 晚上 2 小时      [安排今天放松 →]
```

- 卡片动作：**在想玩/在玩/通关之间移动**，就是最轻的进度管理。
- 意义在于"娱乐也是计划的一部分"，避免工作和休息互相侵占。

### 3.8 数据与设置

```
数据状态
· 数据文件：<文件夹>/data/data.json      [打开文件夹]
· 上次保存：今天 14:32（已保存 ●）
· 数据量：任务 128 · 备忘 12 · 其他…

[ ⬇ 导出备份 ]   [ ⬆ 从备份恢复 ]
────────────────────────────────
偏好设置
· 每天几点算"新的一天"   [ 00:00 ▾ ]
· 逾期任务是否在首页提醒  [ 开 ]
· 本周健身目标天数       [ 5 ]
· 界面密度                [ 舒适 / 紧凑 ]
────────────────────────────────
⚠ 危险操作
[ 清空所有数据 ]（需输入"确认清空"二次确认）
```

- 导出 = 下载一个备份文件；恢复 = 选一个备份文件覆盖。
- 服务器每天自动留一份备份（保留最近 20 份），防手滑。

## 4. 跨模块流转规则（最容易出错的部分）

### 4.1 任务只有一个归属，多个视图

```
任务 { 内容, 归属模块, 日期, 状态, 优先级 }
   ├─ 出现在「归属模块」的清单里（永久）
   └─ 当日期 = 今天 → 出现在首页 & 今日计划
```

勾选在哪儿打，两边同时变。删掉就彻底没了。

### 4.2 逾期处理（不自动搬）

- 过了日期还没完成 → 标记「逾期」，**留在原日期**，首页露出提醒。
- 首页提供：`挪到今天` / `改日期` / `完成` / `放弃`。
- 支持一次性"全部挪到今天"。
- 为什么不一键自动顺延：自动顺延会让清单永远在滚雪球，看不住真实欠账。

### 4.3 模块 → 今日计划的两条通路

| 通路 | 场景 |
|---|---|
| 「推送到今日」按钮 | 明确知道今天要做 |
| 排期（发布日、回访日） | 到那天自动出现在首页 |

（首页**不再**提供 `+ 安排健身` 这类建议入口，见 D8。）

### 4.4 从首页跳回模块

来源标签可点，跳到该模块并高亮那条任务。避免了在 9 个页面之间凭记忆找。

## 5. 反馈与状态（不写代码也要先定）

| 场景 | 表现 |
|---|---|
| 保存中 | 顶栏黄点「保存中…」 |
| 已保存 | 绿点「已保存 14:32」 |
| 保存失败 | 红点 + 提示「数据没写进去，点我看原因」，并保留在内存里不丢 |
| 删除 | 立即消失 + 底部「已删除 · 撤销」5 秒 |
| 空列表 | 显示建议动作，不是空白 |
| 操作冲突（另一个窗口改了同一份数据） | 提示"数据已被其他窗口更新，点击刷新"，不静默覆盖 |

## 6. 已确认的设计选择（原待确认 4 项）

| # | 选择 | 结论 |
|---|---|---|
| 1 | 导航位置 | **左侧固定栏**，显示各模块今日欠账数 |
| 2 | 自媒体看板 | **只用左右箭头按钮**换列，不做拖拽 |
| 3 | 首页智能建议 | **不要**。首页只显示亲手安排的任务，补任务靠顶栏快速添加或首页「快速补一条」 |
| 4 | "新的一天" | **固定 0 点**（本地时间），不提供设置项 |

> 完整需求与验收标准见 `PRD.md`。
