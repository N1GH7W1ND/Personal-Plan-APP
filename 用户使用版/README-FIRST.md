# 用户使用说明

> 这个文件的中文名叫 **用户使用说明**。
> 文件名用的是英文 `README-FIRST.md`，因为启动脚本（.cmd）里不能出现中文
> （原因见最后一节"为什么有些文件名是英文的"）。
> **打开方式**：右键点它 → 打开方式 → 记事本。

这是一个**只在你自己的电脑上运行**的小工具：记任务、记学习、记读书、记饮食、记健身。
不上传任何东西，不需要注册，不需要登录，**数据只存在你自己电脑上的这个文件夹里**。

---

# 第一部分：第一次使用前的准备（只做一次）

这个工具需要一个叫 **Node.js** 的东西才能跑起来。它是免费的，装一次以后就不用管了。

**没装 Node.js 的时候**，你双击 `开始.cmd`，黑色窗口会显示 `Node.js was not found`，
然后就停住了——这是正常的，照着下面做完就好了。

## 第 1 步：确认你的电脑是 64 位还是 32 位

> 这一步可以跳过。**绝大多数电脑都是 64 位**，直接按 64 位装就行。
> 只有很老的电脑才需要确认。

想确认的话：

1. 按键盘上的 **`Win` 键 + `I`**（Win 键是键盘左下角那个窗户图标），打开"设置"
2. 点 **"系统"**
3. 往下找 **"关于"**（或者"系统信息"），点进去
4. 找 **"系统类型"** 这一行，会写着：
   - `基于 x64 的处理器` → 你是 **64 位**，装 `x64`
   - `基于 x86 的处理器` 或 `32 位操作系统` → 你是 **32 位**，装 `x86`

## 第 2 步：打开下载页面

1. 打开你的浏览器（Edge、Chrome 都行）
2. 在**最上面的地址栏**（不是搜索框，是输网址的那一条）里，输入这个网址：

   ```
   https://nodejs.org/en/download
   ```

3. 按回车，等页面加载出来

> **如果打不开**：可能是网络问题。换个时间再试，或者用手机热点试一下。

## 第 3 步：点下载

页面加载完，你会看到很多按钮。**只看这两个**：

| 你想装哪个版本 | 找这个按钮 | 说明 |
|---|---|---|
| **64 位**（绝大多数电脑） | **`Windows Installer (.msi)`** 下面写着 **`64-bit`** 的那个 | 点它 |
| **32 位**（老电脑） | **`Windows Installer (.msi)`** 下面写着 **`32-bit`** 的那个 | 点它 |

**怎么分清 LTS 和 Current？**

页面上会分成两组，一组叫 **`LTS`**（旁边常写着 *Recommended for most users*），
另一组叫 **`Current`**（*Latest Features*）。

> **一定要选 `LTS` 那一组。**
> LTS 是"长期维护版"，最稳。Current 是尝鲜版，不要用。

**很多网站会把 LTS 放在前面**，所以一般就是页面上**第一组**里的
`Windows Installer (.msi)` → `64-bit`。

点下去之后，浏览器会开始下载一个文件，名字大概是：

```
node-v22.20.0-x64.msi
```

（中间那串版本号会不一样，没关系。）

> **下载的文件一般会出现在**：浏览器右上角的下载图标点开能看到，
> 或者在你电脑的 `下载`（Downloads）文件夹里。

## 第 4 步：安装

1. 找到刚下载的那个 `.msi` 文件，**双击它**
2. 可能会先弹出一个"是否允许此应用对你的设备进行更改？" → 点 **"是"**
3. 出现安装向导，**一路点 `Next`（下一步）就行**：
   - 勾选同意条款 → `Next`
   - 安装位置 → **不用改**，直接 `Next`
   - 有个页面会显示要装什么（Node.js runtime、npm 等）→ **不用改**，直接 `Next`
   - 有个页面问要不要装额外工具（Tools for Native Modules）→ **不要勾**，直接 `Next`
   - 点 **`Install`（安装）**
4. 等到进度条走完，点 **`Finish`（完成）**

> 整个过程一两分钟。如果中途杀毒软件提示，选"允许"。

## 第 5 步：回来启动

**把之前那个黑色窗口关掉**（如果它还开着），然后重新**双击 `开始.cmd`**。

这次应该就能看到它开始启动了。

> **装完之后还是提示找不到 Node.js？**
> 把黑色窗口全关掉，重新双击一次。因为命令行的"环境变量"要新开的窗口才会生效。
> 还不行就**重启一次电脑**，再双击。

## 第 6 步：确认装好了（可选）

想确认的话，可以自己看一下：

1. 按 **`Win` 键 + `R`**，弹出运行框
2. 输入 `cmd`，按回车，会开一个黑色窗口
3. 输入下面这行，按回车：

   ```
   node -v
   ```

4. 如果显示出类似 `v22.20.0` 这样的版本号，就说明装好了
5. 关掉这个窗口

# 第二部分：日常使用

Node.js 装好之后就**再也不用管它了**，以后每次只是双击 `开始.cmd`。

## 打开

1. **双击 `开始.cmd`**
2. 会弹出一个黑色窗口，稍等几秒
3. 浏览器会**自己打开**这个工具

> 黑色窗口里会显示一个网址，形如 `http://127.0.0.1:41730/`。
> 如果浏览器没自动打开，**手动把这个网址复制到浏览器地址栏**，按回车也行。

## 一定要记住的三件事

### 1. 那个黑色窗口**不要关**

它就是这个工具的运行程序。窗口一关，浏览器里的页面立刻就用不了了
（会显示"无法连接本地服务"）。

**用完再关**：点窗口右上角的 ×，或者在窗口里按 `Ctrl` + `C`。

### 2. `data` 文件夹是**你的全部数据**，别删

你的任务、备忘、读书进度、饮食、健身记录，全都在这个文件里：

```
data\data.json
```

- **想备份**：把整个 `data` 文件夹复制一份到别处（U 盘、网盘都行）
- **想换电脑**：把整个文件夹拷过去，**包括 `data`**
- 里面还有个 `data\backups\` 文件夹，是程序自动留的每日备份，**出事时能救命，别删**

### 3. 别手动改 `server` 和 `web` 里的文件

那两个文件夹是程序本身，改了会坏。

## 怎么用这个工具

| 想做什么 | 怎么做 |
|---|---|
| 加一条任务 | 首页"快速补一条"，或者各板块里加 |
| 看今天要做什么 | 左边点「今日计划」 |
| 记读书 | 左边点「阅读」，加书、记页码 |
| 记健身 | 左边点「健身」，填练了多久就行 |
| 随手记一句话 | 首页右边「快速备忘」 |
| 某个板块用不上 | 「数据与设置」→「左侧板块选择」，取消勾选 |
| 看统计 | 每个板块页下面都有日历和图表 |
| 备份 / 换电脑 | 复制整个文件夹 |
| 关闭 | 关掉那个黑色窗口 |

小提示：左边栏按键盘数字 `1`–`8` 可以直接切页面，按 `A` 快速加任务。

# 第三部分：遇到问题怎么办

### 双击后提示 `Node.js was not found`
照着**第一部分**装一次 Node.js。装完把黑窗口全关掉，再双击。

### 装好了 Node.js，还是提示找不到
关掉所有黑色窗口重新双击。还是不行就**重启电脑**再试。

### 浏览器里显示"无法连接本地服务"
黑色窗口被关掉了。重新双击 `开始.cmd`。

### 双击后浏览器没自动打开
看黑色窗口里打印的地址（形如 `http://127.0.0.1:41730/`），
**手动复制到浏览器地址栏**打开。

### 黑色窗口提示端口被占用
不用管，它会自己往后找别的端口。看黑窗口里实际打印的地址就行。

### 黑色窗口被关了，但好像服务还在跑
双击 `停止.cmd`，它会把残留的进程收掉，然后再重新双击 `开始.cmd`。

### 数据好像不对了
**先别慌，也别急着改。** 程序发现数据文件异常时会自动从备份恢复。
如果确实丢东西了，`data\backups\` 里有历史备份文件，
可以拿到「数据与设置」→「从备份恢复」里用。

### 想让懂电脑的人帮忙看
双击 `运行测试.cmd`，它会把程序从头检查一遍（10 项），
把黑窗口里的内容拍照发给对方，对方就知道问题在哪。

# 第四部分：想删掉它

1. 双击 `停止.cmd`（如果还开着）
2. **先把 `data` 文件夹复制出去**（如果你还想留数据）
3. 把整个文件夹删掉

它没有往系统里装任何东西，所以删除文件夹就干净了。
（你之前装的 Node.js 可以留着，别的程序也可能用得上；想删就去"设置 → 应用"里卸载。）

# 第五部分：这个文件夹里都是什么

| 名称 | 是什么 | 能删吗 |
|---|---|---|
| `开始.cmd` | **双击它启动** | 不能 |
| `停止.cmd` | 端口异常时的兜底 | 不能 |
| `README-FIRST.md` | **就是本文件**（中文名：用户使用说明） | 可删 |
| `server` / `web` | 程序本体 | 不能 |
| `版本信息.txt` | 这一份是什么时候生成的 | 可删 |
| `运行测试.cmd` + `selfcheck.cjs` | 出问题时自检用，平时不用管 | 可删 |
| `data` | **你的数据**（第一次启动后自动出现） | 删了就没了 |

> 打开 `.md` 文件的方法：**右键点它 → 打开方式 → 记事本**。
> 如果双击打不开，就按这个方式打开。

# 附：这个工具会联网吗？

**不会。** 它没有上传数据的能力，代码里也没有任何联网代码。
你的所有内容都只存在自己电脑本地。

唯一需要网络的地方是**上面第一部分那次下载 Node.js**——那是去官网下载安装包，与这个工具无关。
装完之后，这个工具**完全离线可用**。

# 附二：为什么有些文件名是英文的

你可能会注意到，文件夹里有几个英文名（`README-FIRST.md`、`selfcheck.cjs`），
但打开看内容全是中文。这不是偷懒，是**必须这样**：

Windows 的批处理文件（`.cmd`）有个老毛病——它会在切换字符编码**之前**，
就用系统的老编码把整个文件读一遍。如果文件名里带中文，那个中文就得写进 `.cmd` 里面，
这时会被读成乱码；乱码里可能正好出现会破坏语法的符号，
结果就是**双击之后黑窗口一闪就没了，连提示都看不到**。

这个坑我们真的踩过。解决办法是：**`.cmd` 文件里一个中文都不出现**。

所以现在的分工是：

| 谁 | 用什么语言 |
|---|---|
| 启动脚本内部（`.cmd`） | 只能英文 |
| 黑窗口上显示的提示 | 只能英文（否则可能乱码，甚至闪退） |
| **给你看的说明（就是本文件）** | **全中文** |
| 程序界面（浏览器里的网页） | 全中文 |

黑窗口那几句英文看不懂没关系——下面把常见的几句都翻译并解释了。

## 黑窗口提示对照表

| 黑窗口上显示的英文 | 意思 | 你该做什么 |
|---|---|---|
| `[ERROR] Node.js was not found on this computer.` | 没找到 Node.js | 照第一部分装一次 |
| `Step-by-step instructions ... Opening it now...` | 正在帮你打开这份说明 | 等一下，说明文件会自己弹出来 |
| `Starting the app...` | 正在启动 | 等浏览器自己打开 |
| `Stopped. You can close this window.` | 已停止 | 可以关窗口了 |
| `The app stopped with exit code N.` | 程序异常退出了 | 往上翻看红色或报错信息，拍照发给懂电脑的人 |
| `[ERROR] The Node.js at "..." cannot run.` | 找到的 Node 有问题 | 把 `runtime` 文件夹删掉，重装一次 Node.js |
| `The app stopped with exit code -1.` 或窗口一闪就没了 | 脚本本身没跑起来 | 拍照或录屏发给懂电脑的人，并说明"窗口一闪就消失" |
