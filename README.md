# 我的工作台

一个**只在自己电脑上运行**的「工作 + 生活」小应用。
数据存成本机文件，不联网、不注册、不上传、没有云。

---

## 一、它解决什么问题

日常的工作和生活事项通常散在好几个地方：待办清单一个 App、读书笔记一个文档、健身记录一张表格、想吃什么靠脑子记。
结果就是——**要做事的时候得先想"那件事我记在哪儿了"**。

这个应用把它们收进同一个页面：

- **一份任务清单**，归属到不同板块、带一个日期。电脑上和手机无关，只在这台机器上。
- **每个板块有自己的一页**：清单 + 月历 + 统计图表。
- **数据就是硬盘上的一个文件**。刷新、关浏览器、重启电脑都不会丢；想备份就复制那个文件。

它刻意做小的部分：

| 不做 | 为什么 |
|---|---|
| 不联网、不要账号 | 数据只属于这台电脑，没有服务器可以泄露 |
| 不自动替你安排任务 | 首页只显示你亲手排的事，不做"智能推荐" |
| 不把逾期任务自动顺延 | 没做完就是没做完，留在原日期标红。自动顺延会让清单滚雪球，真实欠账就看不出来了 |
| 不用第三方库、不需要构建 | 代码就是能直接读的 HTML / CSS / JS，几年后依然能跑 |

## 二、主要功能

### 8 个页面

| 页面 | 里面有什么 |
|---|---|
| **首页总览** | 左列：今日计划（可勾选）、快速补一条、逾期提醒；右列：**快速备忘**。底部是**所有板块的汇总图表** |
| **今日计划** | 按日期看当天全部任务、逾期任务、当天小结，下方有跨板块的**任务日历** |
| **开发** | 待办（未开始 / 开发中 / 联调测试 / 已上线）、**灵感收集箱**（可一键变待办）、开发日历、开发统计 |
| **学习** | 学习清单（阅读 / 课程 / 练习 / 视频 / 其他 + 未开始 / 学习中 / 已学完 + 已学时长）、学习日历、学习统计 |
| **阅读** | 书架（想读 / 在读 / 已读完 / 搁置 + 进度条 + 评分）、**读书笔记**（摘抄 / 想法 / 疑问 / 待办，可挂到某本书并记章节与页码）、今日目标与本周概览、阅读日历、阅读统计 |
| **饮食** | 今日三餐、常吃菜谱、采买清单、饮食日历、饮食统计 |
| **健身** | 记录训练（类型 / 时长 / 强度（轻松 / 正常 / 吃力）/ 动作）、每周训练目标与进度、连续天数、健身日历、健身统计、训练记录 |
| **数据与设置** | 数据状态、备份与恢复、**左侧板块选择**、清空数据 |

### 每个板块页都是同一套结构

```
自己的清单  →  自己的月历  →  自己的统计图表
```

- **清单**：新增、编辑、删除（删除后 5 秒内可撤销）
- **月历**：周一开头，今天那格有边框；有内容的日子显示圆点，完成的点是绿色；点某天展开那天的内容
- **图表**：柱形图（每天或每月）+ 扇形图（完成 / 未完成；首页是各板块分布），可切 `本周 / 本月 / 今年 / 全部`，点柱子或扇形可筛选明细；**日历和图表只看不改，翻月、切范围都不会动你的数据**

### 左侧显示哪些板块，可以自己定

「数据与设置」里有一块「**左侧板块选择**」：

- 勾选要显示的板块（开发 / 学习 / 阅读 / 饮食 / 健身），用 ↑ ↓ 调顺序
- **至少要保留一个板块**：一个都不勾会自动回到只显示「学习」；勾了两个及以上时「学习」也可以取消
- 调完立刻生效：左侧栏顺序会变，**「快速添加」里的板块顺序也跟着变**
- 被关掉的板块只是不显示，**板块本身还在**——任务上的板块标签、旧书签都还能进去

首页总览、今日计划、数据与设置是应用骨架，固定显示，不参与勾选。

### 跨板块统一的规则

- **优先级四档**：重要且紧急 / 重要不紧急 / 不重要但紧急 / 不重要不紧急，所有板块统一，列表按这个顺序排。
  **新增任务时默认选中「重要且紧急」**，不想这么高就在弹窗里改。
  旧的"重要 / 普通"两档数据会自动迁移，轻重关系不变。
- **任务只有一个来源**：一份数据、带一个板块和一个日期。板块页和首页看的是同一份，不会两处不一致。
- **推进到今日**：开发待办、学习条目、书、菜谱、训练，都能一键生成一条今日任务。
- **快速备忘不归属任何板块**：只记在首页右列，勾掉就划掉，也能一键升级成任务。
- **删书会连带删掉它的笔记**（笔记挂在书上，书没了就成了没主人的数据），5 秒内可撤销。

### 几个自己会判断的地方

| 场景 | 行为 |
|---|---|
| 阅读读到最后一页 | 自动变成「已读完」并记下完成日期 |
| 阅读新建时就填了已读页数 | 状态立刻变成「在读」 |
| 笔记位置只填了「到第几页」 | 自动把起始页补成同一个，不会出现"第 页–45 页" |
| 健身只填了时长、或只填了动作 | 都算一次训练；两样都没有才不记录 |
| 健身同一天记两次 | 合并成一条：时长累加，同名动作合并（组数累加、次数取更好的） |
| 健身连续天数 | 今天还没练不算断（从昨天往前数） |
| 健身"每周目标" | 默认每周 3 次；完全没练时首页会提醒 |
| 阅读"今日目标" | 默认每天 30 分钟 |
| 动作写法 | `卧推 4x12`、`卧推 4 x 12`、`卧推 4 12` 都认 |

## 三、安装方法

### 需要什么

**Node.js 18 或更高版本**（唯一的依赖）。除此之外不需要装任何东西——
本项目零第三方依赖，没有 `node_modules`，没有构建步骤，不需要联网安装包。

### 第 1 步：装 Node.js（如果已经有了可跳过）

1. 打开 <https://nodejs.org/en/download>
2. 下载 **LTS** 那一组的 **Windows Installer (.msi) → 64-bit**
   （极老的电脑才选 32-bit；不要选 Current 那一组）
3. 双击下载好的 `.msi`，一路点 `Next` → `Install` → `Finish`
4. 验证：按 `Win + R`，输入 `cmd` 回车，在黑窗口里输入下面这行并回车：

   ```
   node -v
   ```

   显示出类似 `v22.20.0` 的版本号就说明装好了。

> **装完还是提示找不到 Node？** 把命令行窗口全部关掉重新开（环境变量要新窗口才生效），
> 还不行就重启一次电脑。

### 第 2 步：拿到这份代码

- 如果是下载的压缩包：**右键 → 全部解压缩**，解压出一个真文件夹再用。
  ⚠️ **不要直接在压缩包里双击运行**——Windows 把 zip 显示成文件夹，但那是个临时假目录，程序跑不起来。
- 如果是 `git clone` 下来的，可以直接用。

### 第 3 步：启动

双击文件夹里的 **`启动.cmd`**。

### 给不想碰命令行的人：`用户使用版/`

仓库里有一个 `用户使用版/` 文件夹，是**可以直接压缩发给别人**的一份：

- 里面只有运行需要的东西（服务端 + 界面 + 启动器 + **用户使用说明（必看！）.md**）
- 不含需求文档、测试、开发工具
- 那份说明是给完全不懂技术的人写的，第一部分逐步教怎么装 Node.js
- 压缩后约 126 KB

它由 `工具_生成用户使用版.cjs` 从主项目生成，保证和主代码一致。

## 四、使用方法

### 打开与关闭

1. **双击 `启动.cmd`** → 弹出一个黑色窗口 → 浏览器会自动打开应用
2. **那个黑色窗口不要关**，它就是本地服务；关了页面就打不开了
3. 用完后关掉黑窗口即可停止；想再打开就再双击一次（已经在运行时会直接帮你打开页面，不会起两份）

> 浏览器没自动打开？看黑窗口里打印的地址（形如 `http://127.0.0.1:41730/`），
> 手动复制到浏览器地址栏即可。

### 快捷键

| 按键 | 作用 |
|---|---|
| `1` – `8` | 按左侧顺序切到对应页面 |
| `A` | 打开「快速添加」 |
| `Esc` | 关闭弹窗 |
| `Enter` | 在快速添加/快速备忘的输入框里回车即提交 |

正在输入框里打字时，数字键属于输入内容，不会被当成快捷键。

### 日常怎么用

| 想做什么 | 怎么做 |
|---|---|
| 记一件事 | 顶栏 `+ 快速添加`（或按 `A`）：填内容、选板块、选日期、选优先级 |
| 看今天 | 左侧「今日计划」；想翻别的日子用上方的日期切换 |
| 加开发待办 | 「开发」页 → `+ 加待办` |
| 收集灵感 | 「开发」页 → 灵感收集箱输入框，回车即存；点「变成待办」升级 |
| 加学习内容 | 「学习」页 → `+ 加内容`：选类型、进度、已学时长 |
| 加一本书 | 「阅读」页 → `+ 加一本书`（填了总页数才有进度条） |
| 记一次阅读 | 「阅读」页 → `记阅读`，填时长，可顺便推进页码 |
| 记读书笔记 | 「阅读」页 → `记笔记`，或书那一行右侧的「记笔记」 |
| 安排今天吃什么 | 「饮食」页 → 三餐直接填，或从「常吃菜谱」点「安排到今天」 |
| 采买清单 | 「饮食」页 → 采买清单输入框；买完点「清空已买」 |
| 记一次训练 | 「健身」页 → 记一次训练，填时长即可；动作可写 `卧推 4x12` |
| 设训练目标 | 「健身」页 → 训练目标，例如「胸 + 三头 每周 2 次」 |
| 随手记一句 | 首页右列「快速备忘」，回车即存 |
| 把东西排到今天 | 各页的「推送到今日」按钮 |
| 收起某页用不上的板块 | 「数据与设置」→「左侧板块选择」 |
| 看统计 | 各板块页下方的日历与图表 |

### 数据在哪、怎么备份

数据全在这个文件夹里，**不会跑到别的地方**：

```
data/
├─ data.json        你的全部数据（纯文本，记事本可以直接打开看）
└─ backups/         自动备份，最多保留最近 20 份
```

- 每次改动自动保存，右上角会显示「已保存 14:32」
- **每天第一次写入前**会自动留一份当日备份
- 如果 `data.json` 被改坏了，下次启动会**自动从最近的备份恢复**，并把坏文件改名成 `data.broken_时间.json` 留证据

**备份**：「数据与设置」→「⬇ 导出备份」，下载一个 json 文件，放到安全的地方。
或者更简单——**直接复制整个 `data/` 文件夹**。

**恢复**：「数据与设置」→「⬆ 从备份恢复」→ 选那个文件。
覆盖前会自动把当前数据另存一份到 `data/backups/`，恢复错了还能找回来。

**换电脑**：把整个文件夹拷过去，双击 `启动.cmd` 就能接着用（新电脑仍需装 Node.js）。

### 出问题了怎么办

| 现象 | 怎么办 |
|---|---|
| 双击后窗口一闪就没了 | 检查是不是**直接在压缩包里运行的**。必须先"全部解压缩"，进真文件夹再双击 |
| 提示 `Node.js was not found` | 装一次 Node.js（见上面"安装方法"第 1 步），装完把黑窗口全关掉再试 |
| 浏览器没自动打开 | 看黑窗口里打印的地址，手动复制到浏览器 |
| 页面显示「无法连接本地服务」 | 黑窗口被关了。重新双击 `启动.cmd` |
| 提示端口被占用 | 不用管，它会自动往后找端口（41730–41739），看黑窗口打印的实际地址 |
| 黑窗口丢了但端口还被占着 | 双击 `停止.cmd` 收尾，再重新启动 |
| 提示「已从备份恢复」 | 说明上次数据文件写坏了，已自动恢复，检查一下最近的数据有没有缺 |
| 想看数据长什么样 | 「数据与设置」→「打开数据文件夹」，用记事本打开 `data.json` |
| 图表显示"这个时间段还没有数据" | 那个时间段确实没有内容，换个范围（比如 `全部`）看看 |

## 五、开发者看这里

### 技术选型

| 项 | 选择 |
|---|---|
| 运行环境 | Node.js（只用内置模块，**零第三方依赖**） |
| 前端 | 原生 HTML / CSS / ES Module，无框架、无构建步骤 |
| 数据 | 单个 JSON 文件 + 原子写入 + 每日备份 |
| 服务 | 只监听 `127.0.0.1`（本机），端口 41730–41739 自动挑选 |

### 目录结构

```
夜少的First-APP/
├─ 启动.cmd / 停止.cmd        启动与兜底
├─ server/                    本地服务（6 个文件）
│   ├─ index.js               入口：挑端口、开浏览器、起服务
│   ├─ store.js               读写数据、每日备份、损坏自动恢复
│   ├─ api.js                 接口
│   ├─ static.js              静态文件
│   ├─ config.js              路径与端口等配置
│   └─ reveal.js              打开数据文件夹
├─ web/                       界面（20 个文件）
│   ├─ index.html             页面骨架（导航 + 顶栏 + 内容区）
│   ├─ styles.css             样式
│   ├─ logic.js               全部业务规则（纯函数，可在 Node 里直接测）
│   ├─ ui.js                  通用组件：弹窗、按钮、图表
│   ├─ app.js / router.js     页面装配与路由
│   ├─ store.js / api.js      前端状态与通信
│   ├─ date.js                本地时区安全的日期工具
│   └─ views/                 9 个页面模块
├─ test/                      自动化测试（328 项）
├─ docs/                      设计稿与验收结论
├─ 发布模板/                   用户使用版的素材源
├─ 用户使用版/                 可直接发给别人的成品
├─ 工具_生成用户使用版.cjs      生成/校验用户使用版
├─ 工具_取历史版本.cjs          从 Git 历史取回文件旧版本
├─ data/                      你的数据（不进版本库）
├─ PRD.md                     需求文档
├─ DEV-PLAN.md                开发计划与协作约定
└─ LICENSE                    许可证（MIT）
```

### 跑测试

```bash
node test/run-all.js                      # 全部 332 项，约 25 秒
node test/run-frontend.mjs test/web-logic.mjs   # 只跑某几个文件，约 1 秒
```

测试是纯 Node 脚本，不需要装测试框架。常用参数：

| 文件 | 覆盖 |
|---|---|
| `test/phase1.js` | 地基：服务启动、静态文件、路径安全、端口 |
| `test/phase2.js` | 数据持久化：原子写入、备份轮换、损坏恢复、冲突 |
| `test/web-logic.mjs` | 业务规则（最大的一份） |
| `test/web-views.mjs` | 真实点击流程 |
| `test/web-date.mjs` | 日期工具 + 样式健康检查 |
| `test/phase7.js` | 总验收：交付件、文档与实现一致性 |
| `test/phase8.js` | 用户使用版 + 取历史版本工具 |

### 两个工具

```bash
node 工具_生成用户使用版.cjs            # 生成用户使用版（--check 只校验）
node 工具_取历史版本.cjs --list <路径>   # 看某个文件的改动历史
node 工具_取历史版本.cjs --deleted <路径>  # 看它被删除的提交
node 工具_取历史版本.cjs --show <版本>:<路径> --out <文件>
node 工具_取历史版本.cjs --verify <版本>:<路径>
```

### 协作约定

见 `DEV-PLAN.md` 第 4.5 与 4.6 节。要点：

- 动手前先说方案
- 一轮只做一件事
- 代码改动跑完测试先确认再提交；文档照常提交
- 用户使用版**等主项目测试通过后再同步**
- 删功能之前先单独提交一次存档
- 取历史文件只用"文件重定向"，不用管道

## 六、不想用了

- **只清数据**：「数据与设置」→「清空所有数据」（需要输入确认文字，且会先自动备份）
- **彻底删掉**：直接删掉整个文件夹。删之前建议先导出一次备份

## 附：这个应用会联网吗

**不会。** 代码里没有任何联网上传的逻辑，服务只监听 `127.0.0.1`，
唯一的网络行为是往本机地址发请求。

安装 Node.js 那一步需要网络，那是去官网下载安装包，与本应用无关。
装完之后，这个应用**完全离线可用**。
