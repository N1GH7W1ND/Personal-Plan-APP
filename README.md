# 我的工作台

一个只给自己用的「工作 + 生活」本地小应用。数据存在这台电脑上，不联网、不需要登录、不上传任何地方。

---

## 有哪些页面

左侧导航共 **8 个入口**：

| 页面 | 里面有什么 |
|---|---|
| **首页总览** | 今日计划（可勾选）、快速补一条、逾期提醒、**快速备忘（整列）**，底部是**所有模块的汇总图表** |
| **今日计划** | 按日期看当天全部任务，可翻日期；下方有跨模块的**任务日历** |
| **开发** | 待办四档状态、灵感收集箱（可一键变待办）、开发日历、开发统计 |
| **学习** | 学习内容清单（阅读/课程/练习/视频/其他 + 三档进度 + 已学时长）、学习日历、学习统计 |
| **阅读** | 书架（想读/在读/搁置/已读完 + 进度条 + 评分）、今日目标与本周概览、**读书笔记**、阅读日历、阅读统计 |
| **饮食** | 今日三餐、常吃菜谱、采买清单、饮食日历、饮食统计 |
| **健身** | 记录训练（类型/时长/强度/动作）、每周训练目标与进度、健身日历、健身统计、训练记录 |
| **数据与设置** | 数据状态、导出备份、从备份恢复、清空数据、偏好设置 |

**每个模块页都有三样东西**：自己的清单 → 自己的**月历** → 自己的**统计图表**。

### 左侧栏显示哪些模块，由你决定

「数据与设置」里有一块「**左侧板块选择**」：

- 勾选要显示的板块（开发 / 学习 / 阅读 / 饮食 / 健身），用 ↑ ↓ 调顺序
- **至少要保留一个板块**：如果一个都不勾，会自动回到只显示「学习」
- 勾了两个及以上时，「学习」也可以取消
- 调完立刻生效：左侧栏的顺序会变，**「快速添加」里的模块顺序也跟着变**
- 被关掉的模块只是不显示在左侧栏，**模块本身还在**——任务上的模块标签、旧书签都还能进去

首页总览、今日计划、数据与设置是应用骨架，固定显示，不参与勾选。

### 健身怎么用

- **记一次训练**：填「练了多久」就行；也可以写动作，每行一个，格式 `卧推 4x12`。
- **同一天记两次会合并**：时长累加，同名动作合并（所以练完想起还有一组，再记一次就好）。
- **训练目标**：例如「胸 + 三头 每周 2 次」，卡片上会显示本周练了几次、还差几次。
- **连续天数**：今天还没练不会算断（从昨天往前数），下午练完就接上了。
- **每周健身目标**在「数据与设置」里改。

### 阅读怎么用

- **加书**：填书名就行；填了总页数才会有进度条。新建时如果已经读到某一页，状态会自动变成「在读」。
- **推进进度**：编辑那本书时直接填「已读到第几页」，或记一次阅读时顺便填页数。读到最后一页会**自动变成「已读完」**并记下完成日期。
- **今日目标**：默认每天 30 分钟（在「数据与设置」里改）。记一次阅读会累加到当天，本周七个格子会亮起来。
- **笔记**：就在阅读页里。可以快速记一句，也可以点「+ 记一条」选「摘抄 / 想法 / 疑问 / 待办」、挂到某本书、填章节、页码区间（第 42–45 页）、行号区间（第 3–8 行），还能收藏置顶；上面有搜索框和按书/类型筛选。
- **删书**会连带删掉它的笔记（避免留下找不到主人的笔记），5 秒内可撤销。
- **位置只填一半也没关系**：只填「到第几页」会自动把起始页补成同一个，不会出现"第 页–45 页"。

### 日历怎么看

- 星期一开头，今天那格有边框；有内容的日子显示圆点，**完成的点是绿色**。
- **点某一天**，下方展开那天具体有哪几件事；再点一次收起。
- `◀` `▶` 翻月，`回到本月` 一键跳回。
- 每页的日历月份是**各自独立**的，你在开发页翻到下个月，学习页仍是本月。

### 图表怎么看

- **柱形图**：每天（本周/本月）或每月（今年/全部）的任务量与完成量。
- **扇形图**：模块页显示"完成 / 未完成"占比；**首页显示各模块的任务分布**。
- **切时间范围**：`本周` `本月` `今年` `全部`，点了立刻重算。
- **点柱子或扇形**：下方明细只显示你点的那一段；点`看全部`取消。
- 首页点扇形图例里的**模块名**可以跳到那个模块；点扇区则只筛选明细、不跳页。

## 怎么打开

**双击文件夹里的 `启动.cmd`。**

- 会自动打开浏览器并进入应用；**那个黑窗口不要关**，它是本地服务，关了应用就打不开了。
- 用完后，关掉黑窗口即可停止。
- 想再打开，再双击一次 `启动.cmd`。已经在运行时会直接帮你打开页面，不会起两份。

> 首次使用需要电脑上装有 Node.js（18 或更高版本）。没装的话，双击 `启动.cmd` 会给出提示和下载地址。

## 数据存在哪

都在这个文件夹里，**不会跑到别的地方去**：

```
data/
├─ data.json        你的全部数据（纯文本，记事本可以直接打开看）
└─ backups/         自动备份，最多保留最近 20 份
```

- 每次改动都会自动保存，右上角会显示「已保存 14:32」。
- **每天第一次写入前**会自动留一份当日备份，防止手滑。
- 如果 `data.json` 被改坏了，下次启动会自动从最近的备份恢复，并把坏文件改名成 `data.broken_时间.json` 留证据。

## 怎么备份 / 换电脑

**备份**：应用里进入「数据与设置」→ 点「⬇ 导出备份」，会下载一个 json 备份文件，放到你觉得安全的地方（网盘、U 盘都行）。

**恢复**：进入「数据与设置」→ 点「⬆ 从备份恢复」→ 选那个文件。
覆盖前会自动把当前数据另存一份到 `data/backups/`，万一恢复错了还能找回来。

**换电脑**：把**整个文件夹**拷到新电脑，双击 `启动.cmd` 就能接着用。不需要安装任何东西（除了 Node.js）。

## 出问题了怎么办

| 现象 | 怎么办 |
|---|---|
| 双击后浏览器没打开 | 看黑窗口里打印的地址（形如 `http://127.0.0.1:41730/`），手动复制到浏览器 |
| 提示端口被占用 | 它会自动往后找端口，看黑窗口里打印的实际地址即可 |
| 页面显示「无法连接本地服务」 | 黑窗口被关了。重新双击 `启动.cmd` |
| 黑窗口丢了但端口还被占着 | 双击 `停止.cmd` 收尾，再重新启动 |
| 提示「已从备份恢复」 | 说明上次数据文件写坏了，已自动恢复，检查一下最近的数据有没有缺 |
| 想看数据长什么样 | 「数据与设置」→「打开数据文件夹」，用记事本打开 `data.json` |
| 图表显示"这个时间段还没有数据" | 那个时间段确实没有任务，换个范围（比如`全部`）看看 |

## 不想用了 / 想清空

- 只想清数据：应用里「数据与设置」→「清空所有数据」（需要输入确认文字，且会先自动备份）。
- 想彻底删掉：直接删掉整个文件夹。**删之前建议先导出一次备份**。

## 一点设计取舍（为什么是这样）

- **数据是文件，不是浏览器缓存**。所以刷新、关浏览器、重启电脑都不会丢；换浏览器也不受影响。
- **不联网**。全程只访问 `127.0.0.1`（本机），没有账号、没有云、没有遥测。
- **逾期任务不会自动顺延**。没做完就是没做完，留在原日期并标红提醒，由你决定挪不挪——自动顺延会让清单滚雪球，真实的欠账就看不出来了。
- **首页不自动生成任务**。首页只显示你亲手安排的事，不会替你"智能推荐"。
- **只有一份任务数据**。任务归属某个模块、带一个日期，模块页和首页看的是同一份，不会出现两处不一致。
- **优先级是四档**（重要且紧急 / 重要不紧急 / 不重要但紧急 / 不重要不紧急），所有板块统一，列表按这个顺序排。旧的"重要/普通"两档数据会自动迁移，轻重关系不变。**新增任务时默认选中「重要且紧急」**，不想这么高就在弹窗里改。
- **快速备忘不归属任何板块**：它没有板块字段，只记在首页那一列里，勾掉就划掉，也能一键升级成任务。
- **删书会连带删笔记**。笔记是挂在书上的，书没了笔记就成了找不到主人的数据，所以一起清掉（可撤销）。
- **日历与图表都是"看"的，不产生数据**。翻月、切时间范围、点柱子都不会改动你的数据。
- **零依赖**。没有 npm 包、没有构建步骤，代码就是能直接读的 HTML/CSS/JS，几年后依然能跑。
